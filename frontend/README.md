# Frontend

This project was generated with [Angular CLI](https://github.com/angular/angular-cli) version 21.2.23, and uses [bun](https://bun.sh) as its package manager.

## Development server

Run `bun install` once, then `bun start` (or `ng serve`) for a dev server. Navigate to `http://localhost:4200/`. The app will automatically reload if you change any of the source files. API calls to `/api` are proxied to `http://localhost:8080` (see `proxy-conf.json`).

## Code scaffolding

Run `ng generate component component-name` to generate a new component. You can also use `ng generate directive|pipe|service|class|guard|interface|enum`.

## Build

Run `bun run build` to build the project. The build artifacts will be stored in the `dist/` directory.

## Running unit tests

Run `bun test` (or `ng test`) to execute the unit tests via [Vitest](https://vitest.dev).

## Further help

To get more help on the Angular CLI use `ng help` or go check out the [Angular CLI README](https://github.com/angular/angular-cli/blob/master/README.md).
